# Short URL Service

A web-based short link service with:
- Backend API (Node.js + Express + SQLite)
- Frontend (Vanilla JS + CSS, no emoji, no rounded corners)
- Short link management (create, list, delete)
- Long link validation (safe check without real access)
- Custom slug and custom page content
- Redirect timer configuration

## Quick Start
```bash
npm install
npm start
# Open http://localhost:3000
```
