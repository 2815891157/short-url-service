# 短链接服务

PHP + MySQL，兼容 InfinityFree 免费主机。零配置安装。

## 功能

- 创建短链接（自定义后缀 + 标题）
- 访问短链接直接 302 跳转
- 管理所有短链接（查看、删除、访问计数）
- 网址有效性检测（DNS + HEAD，SSRF 防护）
- 全中文界面，无 emoji，直角设计

## 部署到 InfinityFree

1. 把所有文件上传到网站根目录
2. 浏览器打开你的域名
3. 自动进入安装向导，填入数据库信息，点击「一键安装」
4. 完成，直接使用

**不需要手动建表，不需要改代码，全自动。**

## 本地测试

```bash
php -S localhost:8000
# 打开 http://localhost:8000
```

## 文件说明

| 文件 | 用途 |
|------|------|
| `.htaccess` | URL 重写规则 |
| `index.php` | 首页入口（自动跳安装页）|
| `setup.php` | 安装向导（全自动建库建表）|
| `init.php` | 数据库连接 + 工具函数 |
| `api.php` | 所有 API 接口 |
| `s.php` | 短链接跳转 |
| `index.html` | 前端页面 |
| `404.html` | 404 页面 |
| `style.css` | 样式 |
| `app.js` | 前端逻辑 |
| `config.php` | 数据库配置（自动生成，勿手动修改）|
