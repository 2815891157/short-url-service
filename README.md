# 短链接服务

PHP 文件存储短链接服务，无数据库，上传即用。

## 使用方法

1. 下载 zip，解压后全部文件上传到主机根目录
2. 打开你的域名，直接用

没有配置步骤，没有数据库，`data.json` 自动创建。

## 文件说明

| 文件 | 用途 |
|------|------|
| `index.php` | 主页面 |
| `api.php` | API 接口 |
| `s.php` | 短链接跳转 |
| `store.php` | JSON 文件读写 |
| `.htaccess` | URL 重写 |
| `style.css` | 样式 |
| `app.js` | 前端逻辑 |
| `404.html` | 404 页面 |
